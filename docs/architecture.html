JO Harness — System Architecture

Model-Agnostic, Open-Weight Agent Platform

4-Tier Model Cascade Harness: OpenHands SDK Gateway: LiteLLM Proxy Auth: Authentik (OIDC) Observability: Langfuse

Interface Layer
User-facing surfaces — CLI, Web, IDE, API, Automation
Chainlit Chat UI Python Phase 2
Prototype streaming chat UI mounted on FastAPI. Displays tool calls as expandable steps, artifacts as downloadable links.
Open WebUI / React TS / Python Phase 3
Production UI with workspace view, file tree, terminal output, branchable conversations, artifact inspector. Auth via Authentik OIDC.
MCP Clients JSON-RPC Phase 3
IDE integrations (VS Code, Cursor, etc.) and external agents connecting to tool catalog via MCP protocol.
A2A Agents JSON-RPC / SSE Phase 3
External agents delegating tasks via Agent-to-Agent protocol. Discover capabilities via Agent Card.
⚡
API & Service Layer
FastAPI — Auth, sessions, streaming, orchestration
FastAPI Application Python 3.14 Phase 2
Product API layer. Versioned under /api/v1/.
  • Auth routes (Authentik JWT validation)
  • Conversation & message CRUD
  • Agent run/stream/cancel (SSE)
  • Artifact upload/download
  • Tool listing
  • A2A & MCP endpoints (optional)
Authentik OIDC / OAuth2 Phase 2
Self-hosted identity provider. Handles registration, login, password reset, Google/GitHub SSO, and session management.
  • Email/password flows
  • Social login (Google, GitHub)
  • JWKS for JWT validation
  • User self-service portal
Celery Workers Redis broker Phase 2
Agent runs dispatched as async Celery tasks. Enables concurrent multi-user execution. Independently scalable.
  • Task dispatch via Redis
  • SSE event bridging
  • Configurable concurrency
  • K8s HPA ready
🧠
Agent Core
OpenHands SDK behind an AgentRuntime abstraction
AgentRuntime Protocol Python Protocol Phase 2
Thin abstraction preventing harness lock-in. App services depend only on this interface.
  • create_session()
  • run() → AsyncIterator[AgentEvent]
  • steer() / cancel() / approve()
  • close_session()
OpenHands Runtime openhands-sdk Phase 2
Primary implementation. Event-driven loop with planning, tool dispatch, sub-agent delegation, and shared state.
  • Planning before execution
  • Iterative tool/sub-agent orchestration
  • Context compression (condenser)
  • Canonical event emission
  • Artifact generation
Shared State In-memory dict
Mutable state object updated at each agent loop iteration. Holds accumulated observations, plan progress, and intermediate results.
Policy Engine Guardrails Phase 2
Synchronous deterministic guardrails. Enforces token/run budgets, thrasher breaker, argument validation, and PII/Secret scrubbing.

Interoperability & Protocol Map
How external systems connect to JO Harness
REST API HTTP/JSON
Direct programmatic access. Any HTTP client can create sessions, submit tasks, and stream responses.
MCP Server JSON-RPC 2.0
Tools exposed as MCP resources (stateless 2026-07-28 spec). IDEs (VS Code, Cursor) and other agents discover and invoke tools via stdio or HTTP/SSE.
A2A Protocol JSON-RPC + SSE
Agent Card at /.well-known/agent-card.json. External agents delegate tasks and receive streaming updates.
LiteLLM Gateway OpenAI-compatible
All LLM calls flow through LiteLLM. Swap Ollama ↔ Cloud by editing config.yaml. Zero code changes.
